代码规范
遵循 W3C 标准及各框架官方规范。
代码格式统一，命名语义化。
SEO 专项规范：
使用语义化 HTML 标签（<header>, <nav>, <main>, <article>, <footer>等）
确保图片添加alt属性，视频添加字幕轨道
实现响应式设计，确保移动设备友好性
优化页面加载速度（LCP < 2.5s, FID < 100ms）
AdSense 专项规范：
广告容器与内容区域明确分离，避免混淆内容与广告
不使用诱导性语言引导点击广告
确保广告单元尺寸适配各种屏幕（最小宽度不小于 250px）
单个页面广告数量合理（通常不超过内容占比的 30%）
网页开发实践
搜索引擎优化实现：
动态生成页面元标签（title, description, keywords）
实现规范的 URL 结构（静态化、包含关键词、层级清晰）
集成结构化数据（JSON-LD 格式），支持文章、产品等类型
实现站点地图自动更新机制，包含所有重要页面
配置 robots.txt，明确爬取规则和禁止访问区域
实现规范的内部链接结构，确保页面可达性
AdSense 合规实现：
开发响应式广告容器组件，支持自动调整尺寸
实现广告加载优化（延迟加载非首屏广告）
确保广告不覆盖内容，不固定在页面顶部 / 底部
避免在导航菜单、内容中间插入过多广告
实现广告单元错误处理机制，避免空白区域
